QUICK START COMMANDS
────────────────────────────────────────────────────────────────────────────

Install dependencies:
  $ pnpm install

Configure Firebase:
  $ cp .env.example .env.local
  # Edit .env.local with your Firebase credentials

Start development server:
  $ pnpm run dev

Seed initial data:
  $ export FIREBASE_SERVICE_ACCOUNT_KEY="/path/to/service-account-key.json"
  $ pnpm run seed:firebase

Run tests:
  $ pnpm run test
  $ pnpm run test:watch
  $ pnpm run test:coverage

Deploy security rules:
  $ firebase deploy --only firestore:rules

SUPPORT & TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

Issue: Firebase not initialized
  → Check .env.local has all Firebase variables
  → Restart dev server after adding env vars

Issue: Real-time updates not working
  → Verify security rules allow reads
  → Check Firestore console for data
  → Enable debug logging in hooks

Issue: Tests failing
  → Run pnpm install to get testing dependencies
  → Check jest.config.js is in correct location
  → Run pnpm run test:watch for debugging

Issue: Seed script fails
  → Set FIREBASE_SERVICE_ACCOUNT_KEY env variable
  → Download service account from Firebase Console

For more help:
  → See IMPLEMENTATION_GUIDE.md Troubleshooting section
  → Check Firebase documentation
  → Review error messages in browser console
